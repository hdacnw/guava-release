## TOOLS

### `grasp(target_name)`
Grasp the named object by segmenting the named object, aligning the gripper using PCA, then descending and closing onto the named object. Returns `grasped` if an object is grasped successfully or `closed` if the gripper closes without grasping an object.
- For top-down grasp, call `align(target_name, 'top', clearance)` before `grasp()` to position the gripper directly above the object before grasping.
- After a successful grasp, lift with `move()` before travelling sideways.
- If grasp() returns `closed` (gripper closed on air), open gripper with `release()`, then call `align()` again to re-align the gripper to the object before retrying as the object may have shifted.

### `align(target_name, position, clearance)`
Moves the gripper to a selected side of the named object at the chosen standoff distance.
- **position**: `top` | `left` | `right` | `front` | `back` — relative to the camera view
- **clearance**: `small` (6 cm) | `medium` (10 cm) | `large` (20 cm)
- `top`: moves to above the target object's centre. Use before top-down grasp or before releasing a grasped object onto something.
- `left`/`right`/`front`/`back`: moves gripper to horizontally left/right/front/back of the target object. You may use a separate `move()` to adjust height before or after.
- Choose `clearance` by reasoning about both the target object's geometry and any object currently held. For left/right/front/back align, select the appropriate clearance based on the HORIZONTAL (x, y) dimensions of the objects involved. For top align, select the appropriate clearance based on the VERTICAL dimensions (z) of the objects instead. A compact target with an empty gripper can use `small` or `medium`; use `large` when holding a large object to avoid collision with nearby objects. 

### `get_position(target_name)`
Returns `[x, y, z]` position of the named object in the table-aligned frame. Use to check where an object is when the image alone is insufficient.

### `get_position_and_size(target_name)`
Returns the position and bounding-box size of the named object in the table-aligned frame. Use when you need both where an object is and how large it is, e.g. to judge whether something fits inside a container or if we need to avoid collision.

### `move(target_position)`
Moves the TCP to `[x, y, z]` keeping current orientation. Use for lifting after a grasp, lowering for a push, or fine position adjustments when `align` is insufficient.

### `rotate(angle_deg, axis)`
Rotates the gripper in place by `angle_deg` around body-frame axis `x`/`y`/`z`. Call this for fine rotation adjustments that require a specific orientation.

### `close_gripper()`
Closes the fingers without any positioning. Use for preparing a push surface for pushing, or grasping in unusual pose after manually positioning the gripper.

### `release()`
Opens the gripper fully.

### `home_pose()`
Moves the gripper back to the robot's default home configuration. Use as a recovery action when the gripper is in a bad or unreachable pose.

## RULES

- <think> must contain a nonempty, brief public action explanation; never leave it empty.
- Call at most ONE tool per response.
- When placing **onto** a surface or **next to** an object or placing **into** a container, use `move()` to descend close to the target surface before `release()` so the object lands gently.
- When inserting an elongated object (e.g. spoon, pencil) into a narrow container (e.g. mug, cup), use ONE OR MULTIPLE `rotate()`s about the gripper's x axis to tilt it to a roughly perpendicular orientation. The rotation should happen AFTER aligning with the container. 
- For objects with a handle or a part that is designed for grasping, you should always query for the handle for grasping. 
- The `position` argument in `align()` is always in **camera view** reference. For example, if you want to approach the front face of a drawer that is facing the right direction from the camera view, you should call `align()` with `position = right` instead of front.
- For standard top-down grasping, prefer `align()` + `grasp(target_name)`.
- For opening or closing drawer, first `align()` to the opening side of the drawer at a `large` clearance, then apply `grasp()` to grasp the handle, and finally apply `move()` to open or close the drawer. For opening drawer, the pull direction is from the post-grasp gripper position back toward the pre-grasp (gripper pose after `align()`) position. For closing drawer, the push direction is to move further AWAY from the pre-grasp pose. If the gripper barely moves, try the OPPOSITE direction. 
- For pushing, call `align()` to align to object on the opposite of pushing direction e.g. if you are pushing right, you should call `align(position=left)`. You should also close the gripper and lower the gripper near the table surface to create a stable push.
- For placing near an object, call `align()` in an appropriate direction (left/right/front/back) to place the object near the target.  
- When done: <think>...</think> Task complete.
- When irrecoverable: <think>...</think> Task failed.
- You may be resuming from an intermediate state in the task where some steps may already have been completed. Use the gripper state and the image to infer what has been accomplished and what still remains, before reasoning about the next action.
